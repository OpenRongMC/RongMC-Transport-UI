# RongMC 交通界面

简体中文 · [English](./README.en.md)


让 MTR 与共享界面的扩展使用 Oriel 风格，也可随时切回经典外观。MTR 设置与 Mod Menu 都能打开切换入口，选择保存在客户端。用同一套编辑器配置列车、站台和电梯。

## 使用

从 MTR 设置的「界面」入口切换 Classic 或 Oriel。配套 Oriel 可选，缺少时使用经典界面。该适配在共享界面的背景和现有控件上应用外观。

主分支的共享界面背景可以透出游戏画面。从仪表板打开 MTR 设置后，按 Esc 会返回仪表板。

## 安装

在 [GitHub Releases](https://github.com/OpenRongMC/RongMC-Transport-UI/releases/tag/v0.2.0%2B26.3) 下载 **v0.2.0+26.3**。使用 Minecraft Java **26.3**、**Fabric** 和 **Java 25**。 相关项目见 [MTR](https://github.com/OpenRongMC/Minecraft-Transit-Railway)、[Oriel](https://github.com/Rinorsi/Oriel-UI)。 将发行 JAR 放进实例的 `mods/` 目录。 只装在客户端，配套同系列 MTR。需要 Oriel 外观时加装 Oriel；缺少 Oriel 时可继续使用经典模式。
